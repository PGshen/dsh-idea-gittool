## 目标

让用户在 Git tab 里完成日常只读审查：浏览提交图与分页历史、按文本/哈希/分支/用户过滤、查看提交详情与变更文件、打开文件 diff、在分支面板里导航，并通过 Git 控制台确认插件执行了什么。
A1 不写任何仓库内容（提交/分支/贮藏/冲突闭环在 A2/A3）。

## 范围

**包含：**

- Host 只读 RPC 扩展：`branches`、`refs`、`commit`、`diff`、`console`；命令记录（argv/耗时/退出码/输出摘要、凭据脱敏、环形缓冲）。
- 客户端增量提交图布局（lane/颜色/边、分页追加、合并提交、topo/date 排序）。
- 日志页：仓库栏、筛选栏（搜索/分支/用户/图选项/跳转）、虚拟列表、refs 胶囊、选择与键盘。
- 提交详情 + 变更文件树；统一模式 Diff 查看器（含重命名/二进制/大文件截断规则）。
- 分支面板（HEAD/Local/Remote/Tags，单击导航、双击过滤）。
- 状态栏（分支/ahead-behind/工作区摘要/贮藏数/刷新信息）、只读模式与操作状态横幅。
- Git 控制台抽屉（只读展示、复制、清空、暂停滚动）。
- 样式管线落地（TD-3）与刷新可靠性修复（TD-4）；A1 结束后补一次 HMR 与真实刷新走查。

**不包含：**

- 写操作：提交、amend、push、分支动作、stash、reset、revert/cherry-pick（A2/A3）。
- 冲突解决与三栏合并（A3/B1）；文件历史、Blame 内容、比较模式（B2）。
- 并排 diff、词级高亮、忽略空白重算、折叠未改片段（P1/B3；A1 只做统一模式）。
- 日期/路径筛选、收藏、按目录折叠分支、GPG 签名列、多仓库（P1/P2）。
- 设置弹层完整版（A1 只用固定默认值：3s 轮询、每页 100 条、统一 diff）。

### T1：Host 只读 RPC 扩展与命令记录（待开始）

- **目标**：补齐 A1 需要的只读数据，并把每次 git 调用记录成控制台数据。
- **涉及文件**：`src/shared/protocol.ts`、`src/host/rpc.ts`、`src/host/git-executor.ts`、`src/host/git/{branches,commit,diff,refs}.ts`、`src/host/console.ts`、`src/host/http.ts`（端点白名单）、`test/host/*`。
- **接口与要点**：
  - `branches`：`for-each-ref` 一次取 refs/upstream/ahead-behind/是否 HEAD，按 local/remote/tags 分组；收藏（P1）先不返回。
  - `refs`：sha → { locals, remotes, tags, head }（`git for-each-ref --format` 一次拉全量，客户端按 sha 索引）。
  - `commit { sha }`：`show -s --format` + `diff-tree --name-status -z` + `--numstat`；合并提交返回 `parents[]` 与按父分组的文件列表。
  - `diff { path, scope: 'worktree'|'staged'|'commit', sha?, parent? }`：返回结构化 `DiffFile { oldPath, newPath, status, binary, truncated, hunks[] }`，行级 `{ type, oldLine?, newLine?, text }`；单文件 ≤256KiB、总响应 ≤4MiB，超出置 `truncated` 并保留已解析前缀。
  - `console`：环形缓冲（100 条），记录 argv/耗时/退出码/stdout+stderr 摘要（各 ≤64KB）、`user:token@` 脱敏；由 `git-executor` 统一埋点，读写命令都记。
  - 新增端点必须在 `RPC_ENDPOINTS` 与 `http.ts` 校验里登记；路径参数沿用 repo 相对 POSIX + `--` + `GIT_LITERAL_PATHSPECS=1`。
- **测试**：临时仓库覆盖 branches/refs 分组、commit 详情（含 merge 两父）、diff 三种 scope、二进制、重命名、超限、无效 sha/path、console 缓冲与脱敏。
- **完成标准**：端点全部结构化，10k 提交仓库 `branches` ≤ 100ms、`commit` ≤ 50ms；`make check` 绿。
- **验证命令**：`pnpm vitest run test/host`、`make check`。

### T2：样式管线与基础 UI 组件（待开始）

- **目标**：关掉 TD-3，让 A1 的组件有可维护的样式基础。
- **涉及文件**：`build.mjs`、`src/client/styles/*.css`、`src/client/ui/{Button,Chip,StatusLetter,EmptyState,Spinner}.tsx`、`test/client/ui/*`。
- **接口与要点**：
  - 采用 esbuild `local-css` + class map：一次构建产出 CSS 文本与 class map，`apply` 时注入带 `data-plugin-css` 的 `<style>`；构建 smoke 断言 style 注入与 class 存在。
  - 只允许 `--dsw-alias-*` / `--dsw-static-*` token；不写字面色、不写主题选择器（`docs/web-styling.md`）。
  - 先写 ADR 0005 记录「自建 CSS Modules 管线」的取舍（替代内联样式），再实现。
  - 基础组件只做 A1 用到的：按钮（primary/ghost/危险占位）、胶囊（ref/筛选）、状态字母（M/A/D/R/C/T/U 色）、空态/加载态。
- **测试**：构建 smoke 增加「client.js 注入 style」「class 名哈希稳定」；组件用 `renderToStaticMarkup` 断言 token 与语义。
- **完成标准**：原内联样式组件（GitBody/document-actions/read-only-banner）迁移到 CSS Modules，视觉不变；`make check` 绿。
- **验证命令**：`pnpm build && pnpm smoke`、`make check`。

### T3：增量提交图布局算法（待开始）

- **目标**：纯函数产出每行的 lane/颜色/边，支持分页追加与筛选重建。
- **涉及文件**：`src/client/graph/{layout.ts,colors.ts}`、`test/client/graph/*`。
- **接口与要点**：
  - `createGraphLayout({ order: 'date'|'topo', firstParent?, noMerges? })` → `{ append(commits): GraphRow[]; reset(): void; rows: GraphRow[] }`。
  - `GraphRow { sha, lane, colorId, edges: { fromLane, toLane, kind: 'line'|'curve'|'stub'|'dashed' }[], width }`。
  - lane 上限 10（视觉最多 6 色相 + 线型区分）；父提交不在结果集→虚线，已知未加载→实线 stub。
  - 颜色按稳定 colorId 分配，不随滚动变化；筛选/排序变化重建。
- **测试**：线性、合并、octopus、交叉分叉、无关历史、分页追加、first-parent/no-merges；2000 行布局 < 50ms。
- **完成标准**：单元测试覆盖上述历史形状；布局不依赖 DOM；`make check` 绿。
- **验证命令**：`pnpm vitest run test/client/graph`。

### T4：日志页（骨架 + 筛选 + 虚拟列表）（待开始）

- **目标**：Git tab 默认页切换为日志页，分页加载、筛选、键盘与选择可用。
- **涉及文件**：`src/client/pages/LogPage.tsx`、`src/client/pages/{FilterBar,LogTable,LogRow,RefChips}.tsx`、`src/client/store/log-store.ts`、`src/client/index.ts`、`test/client/pages/*`。
- **接口与要点**：
  - 每页 100 条、最多保留 2000 行；`@tanstack/react-virtual` 虚拟化，行高 26px；滚动接近底部自动加载下一页。
  - 筛选：搜索（消息/作者/哈希，`.*` 正则、`Aa` 大小写、600ms 防抖）、分支多选、用户多选、图选项（日期/拓扑、第一父、无合并）、跳转（哈希/分支/标签，失败红框）。

- **测试**：store 分页合并/去重/筛选重建；FilterBar 防抖与胶囊；LogTable 虚拟化行数与键盘选择；空/错误态渲染。

- **验证命令**：`pnpm vitest run test/client/pages`、浏览器走查 + 性能面板。
