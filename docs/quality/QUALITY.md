# 模块质量评级

每个里程碑收尾时更新。评级标准：

| 评级 | 含义 |
|---|---|
| A | 测试覆盖主要路径和边界情况；文档和实现一致；没有已知问题 |
| B | 主要路径有测试；有少量已知缺口，已登记到 tech-debt |
| C | 能用，但测试或文档明显不足 |
| — | 还没有实现 |

| 模块 | 评级 | 已知缺口 | 更新日期 |
|---|---|---|---|
| `src/host/` | B | M0 只读路径（status/log/bootstrap）与门禁有真实仓库测试；写操作、diff/show、大仓库极端场景未做 | 2026-10-25 |
| `src/client/` | C | M0 只有 tab 骨架、bootstrap 摘要与文档动作；无提交图/diff/筛选，样式为内联（TD-3） | 2026-10-25 |
| `src/shared/` | B | 协议常量/类型与 isRpcResult 有单测；RPC 端点契约随实现演进 | 2026-10-25 |
| `build.mjs` | B | 双面产物 + smoke；契约漂移风险见 TD-1 | 2026-10-25 |
| 文档与 harness | B | 计划/ADR 校验已机器化；references §13 已回写 M0 实测，HMR/刷新待补（TD-2） | 2026-10-25 |
